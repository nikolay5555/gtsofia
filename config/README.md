# Ръчни корекции на линии

Файлът `route-overrides.json` съдържа изключения от автоматичната GTFS нормализация.

Ключът на всеки запис е оригиналният GTFS `route_id` (например `TB26`, `A241`), а не номерът, който се показва на таблото.

Поддържани полета:

- `number` — номер/обозначение за показване;
- `type` — `bus`, `tram`, `trolley`, `metro` или `other`;
- `subtype` — `night`, `school`, `temporary` или празен низ `""` за изчистване на автоматично определения подтип;
- `color` — цвят на pill-а в HEX формат, например `#123456`;
- `textColor` — цвят на текста в HEX формат, например `#FFFFFF`.

Всички полета са незадължителни. Задават се само стойностите, които трябва да бъдат променени; останалите продължават да се определят автоматично.

Пример:

```json
{
  "TB26": {
    "number": "184",
    "type": "bus"
  },
  "A226": {
    "color": "#000000",
    "textColor": "#FFFFFF"
  },
  "TB37": {
    "number": "3ТМ",
    "type": "bus",
    "subtype": "temporary"
  }
}
```

Overrides се прилагат след автоматичната нормализация. Те се зареждат от backend-а при стартиране на API модула и от страницата с разписанията при зареждане на GTFS данните. След редакция на файла трябва да се публикува нова версия на сайта/API.
